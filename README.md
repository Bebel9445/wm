# wm : Show war machines across your terminal
## Description

wm (war machine) runs accros your terminal, when you type `wm`. It's juste an adaptation of `sl` created by Toyoda Masashi ([mtoyoda@acm.org](mailto:mtoyoda@acm.org)).

## Installation

### On Arch
Simply use `yay -S wm`

### On other distro
You need to compile the code by yourself

## Usage
`wm [-KLBFIPMbde]`

### Tank selection (only one, if multiple, the first one is selected)
- K : KV-2
- L : Leclerc MBT
- B : BM-13 (Katyusha)
- F : Renault FT-17
- I : IS-2
- P : Panzer IV ausf. H
- M : Maus

### Modifier selection (multiple can be selected)
- b : blitzkrieg, the tank / vehicle goes faster
- d : disco mode, color alternate
- e : escape, allow interrupt by ctrl-c and stop by ctrl-z
